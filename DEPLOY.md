# Загрузка сайта на GitHub и Render

Эта папка содержит только плоский комплект файлов для сайта. Здесь нет Android-проекта, `node_modules` и игровых данных.

## GitHub

1. Создай пустой репозиторий на GitHub.
2. Открой папку `github-upload` на компьютере и выдели её файлы (включая `.gitignore`).
3. В репозитории выбери **Add file → Upload files**, перетащи выбранные файлы и нажми **Commit changes**.
4. Загружай содержимое папки, а не саму папку `github-upload`.

Не загружай в репозиторий `.env`, `data` или `node_modules`.

## Публикация

1. В Render выбери **New → Blueprint**, подключи репозиторий и подтверди настройки из `render.yaml`.
2. Дождись окончания деплоя, затем открой адрес Render. Проверка сервера доступна по адресу `/healthz`.
3. Зарегистрируй игровой аккаунт.

Render Blueprint создаёт постоянный диск, который нужен для сохранения аккаунтов и лотов. Он требует платный план Starter; проверь актуальную стоимость Render перед созданием сервиса.
